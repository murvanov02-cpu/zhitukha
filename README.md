# Житуха — Telegram Mini App

Игра про жизнь: открываешь кейсы с машинами, жильём и отношениями, качаешь навыки,
устраиваешься на работу получше и богатеешь, даже когда не в игре.

## Файлы

- `index.html` — разметка
- `style.css` — оформление
- `js/data.js` — **весь баланс**: предметы, шансы кейсов, работы, цены навыков, статусы
- `js/game.js` — логика игры

## Как поиграть на компьютере

Откройте терминал в этой папке и запустите:

```bash
python3 -m http.server 5173
```

Затем откройте в браузере http://localhost:5173

## Как выложить в Telegram

### 1. Выложить игру в интернет (GitHub Pages, бесплатно)

1. Зарегистрируйтесь на https://github.com
2. Нажмите **New repository**, назовите его, например, `zhitukha`, выберите **Public**, нажмите **Create**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите туда
   `index.html`, `style.css` и папку `js`. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**, в **Branch** выберите `main` и нажмите **Save**.
5. Через 1–2 минуты игра откроется по адресу `https://ВАШ_ЛОГИН.github.io/zhitukha/`

### 2. Подключить игру к боту

В @BotFather: **/mybots → ваш бот → Bot Settings → Menu Button**, отправьте ссылку
из шага 1 и название кнопки, например «Играть».

В новом интерфейсе BotFather то же самое находится в разделе **Mini Apps**.

Готово: откройте бота, и внизу появится кнопка «Играть».

### Как обновлять игру

Загрузите изменённые файлы в тот же репозиторий на GitHub, и через минуту обновление появится у всех.

## Что важно знать

- Прогресс сохраняется **на устройстве игрока**. Если зайти с другого телефона, прогресс будет новым.
- Сохранение можно подделать. Для общего рейтинга, рефералов и покупок за Telegram Stars
  понадобится сервер; это следующий этап.
